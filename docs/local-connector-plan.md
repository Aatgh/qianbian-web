# 千变本机 / 手机连接器方案（待前端确认）

日期：2026-11-24
状态：**方案评审中，暂不开工**
目标：让 Agent 能在用户自己的 Windows 笔记本和 Android 手机上工作，包括文件、终端、桌面 GUI、手机 App 操作。

---

## 1. 结论先说

网页/浏览器无法直接访问用户电脑。要实现，必须在用户设备上安装一个本地程序：

- 电脑：`千变 for Windows`（托盘常驻，内部组件名“千变连接器”）
- 手机：`千变 for Android`（内部组件名“千变连接器”）
- 设备主动通过加密 WebSocket 连接云端，不需要公网 IP、端口映射

云端负责思考和规划，连接器负责在设备上执行，所有危险操作走审批。

```text
网页 / 手机网页
      │
      ▼
千变云：Agent / 会话 / 审批 / 设备网关
      │  WSS（设备主动外连）
      ▼
千变连接器（Windows / Android）
      │
      ▼
文件、终端、桌面 GUI、手机 App
```

### 命名约定（已确认 2026-11-25）

主产品统一叫「千变」，连接器不是独立品牌，而是千变的设备端运行组件。

- Windows 安装包：`千变 for Windows`
- Windows 说明：`千变 for Windows · 本机连接服务`
- Android 安装包：`千变 for Android`
- Android 说明：`千变 for Android · 手机连接服务`
- 安装与下载页面：`千变设备连接`
- 技术文档、协议、日志和内部服务名：`千变连接器`
- 不使用「通用千变」作为安装包名称，避免被理解为第二个主产品或通用 Agent

## 2. 产品范围

### V1 必须做

**千变 for Windows**

- 扫码/配对码绑定设备
- 托盘程序、开机自启、暂停/退出
- 文件：列目录、读取、搜索、写入、编辑、删除（删除审批）
- 终端：执行 PowerShell/CMD，工作目录受限
- 设备权限配置：允许访问哪些目录
- 网页/手机端选择“我的电脑”
- 审批、审计、解绑

**千变 for Android**

- 配对绑定
- 无障碍服务：点击、滑动、返回、打开 App、填表
- 截图/读取当前界面
- 前台常驻通知，一键停止
- 复用现有 XiaoPaiWake 的无障碍和 Shizuku 能力
- 默认禁止支付、银行、删除系统数据

### V2 再做

- Windows 桌面 GUI：截图、鼠标、键盘、窗口操作
- 视觉模型识别屏幕
- 手机屏幕实时预览
- 断网任务排队
- macOS / Linux
- iOS（能力有限，走 Shortcuts/分享扩展）

### 暂不做

- 云电脑
- 浏览器静默提权
- 远程开机
- 绕过系统权限

## 3. 服务端设计

新增设备域：

```text
qb_device
qb_device_permission
qb_device_task
qb_device_audit
qb_device_pair_code
```

核心接口草案：

```text
POST /api/devices/pair/start       生成一次性配对码
POST /api/devices/pair/confirm     连接器确认配对
GET  /api/devices                  当前用户设备列表
PATCH /api/devices/{id}            改名 / 暂停 / 权限
DELETE /api/devices/{id}           解绑
WS   /api/device-gateway           连接器长连接
```

工具层改造：

```text
ExecutionTarget
├── ServerWorkspaceTarget   当前云端工作区
├── WindowsDeviceTarget     用户笔记本
└── AndroidDeviceTarget     用户手机
```

`read_file`、`write_file`、`run_terminal`、`screenshot`、`click` 等工具按当前会话选择的目标设备路由。

连接器能力协商：连接时上报 capabilities，云端只发设备支持的任务。

## 4. 安全设计

必须满足：

1. 用户主动安装、登录、配对，网页不能静默连接本机
2. 每台设备独立令牌，服务端只存哈希
3. 设备主动外连 WSS，不开放入站端口
4. 首次授权目录白名单，默认最小权限
5. 写文件、执行命令、删除、GUI 操作都要审批
6. 默认不以管理员权限运行
7. 支付、银行、密钥库、浏览器密码库默认拒绝
8. 状态栏/托盘可见，随时暂停、解绑
9. 全量审计：用户、设备、操作、参数、结果、耗时
10. 安装包代码签名，自动更新校验签名

## 5. 前端需要做的工作（待确认）

### 5.1 设备管理页

- 设备列表：名称、类型、系统、在线状态、最后在线、权限摘要
- 配对流程：生成二维码/6 位码、复制、倒计时、等待连接成功
- 设备操作：改名、查看权限、暂停、解绑、重新配对
- 空态：安装引导、下载入口、系统要求
- 手机端适配

### 5.2 工作环境选择器

现在已有「云端工作区 / 云电脑」，需要扩展成：

```text
云端工作区
我的笔记本（在线）
我的手机（在线）
```

需要处理：

- 设备离线
- 设备暂停
- 当前设备权限不足
- 连接中 / 重连中
- 切换环境后会话归属

### 5.3 审批卡

需要区分：

- 云端工作区操作
- 本机文件读写
- 本机命令执行
- 桌面 GUI 操作
- 手机无障碍操作

审批文案要显示：设备名、路径/命令、风险等级、允许一次/本会话/拒绝。

### 5.4 本机任务进度

- 当前在哪个设备执行
- 执行步骤、耗时、成功/失败
- 取消任务
- 查看审计记录

### 5.5 可选：屏幕预览

如果要像远控软件一样看桌面/手机画面，需要前端做实时画面组件；V1 可以先只做截图查看，不做实时控制。

## 7. 实施顺序（确认后）

### 阶段 A：设备基础设施

- 设备表、配对码、设备令牌
- WSS 网关、心跳、在线状态
- 前端设备列表 / 配对 UI
- 验收：网页能看到一台设备在线，能解绑

### 阶段 B：Windows 文件 + 终端

- Connector 托盘程序、开机自启
- 目录授权、文件工具、终端工具
- 审批、审计
- 验收：让千变读取桌面文件、整理文档、执行命令

### 阶段 C：Windows 桌面 GUI

- 截图、鼠标、键盘、窗口操作
- 视觉/UI Automation
- 验收：打开浏览器搜索、整理桌面、填写表单

### 阶段 D：Android 连接器

- 无障碍服务、截图、点击
- 前台通知、停止按钮
- 验收：打开 App、完成一组点击

### 阶段 E：体验与安全加固

- 自动更新
- 断线重连
- 权限回收
- 审计查询
- 安装包签名
- 崩溃日志脱敏

---

## 8. 验收标准（V1）

1. 用户能在网页上配对一台 Windows 电脑
2. 能让千变读取授权目录中的文件并总结
3. 能让千变执行一条需要审批的命令
4. 拒绝审批时任务停止，不执行
5. 设备离线/解绑后任务立即失败
6. 手机端能看到设备状态并审批
7. 所有操作有审计记录
8. 不安装连接器时，任何网页操作都无法访问本机
